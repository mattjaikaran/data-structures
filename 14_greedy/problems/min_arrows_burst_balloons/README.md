# Min arrows burst balloons

Practice the matching question: [LeetCode #452: Minimum Number of Arrows to Burst Balloons](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/).

Return the smallest number of positions that intersect every balloon interval.
