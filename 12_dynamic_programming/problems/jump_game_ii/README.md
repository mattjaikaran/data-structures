# Jump game ii

Practice the matching question: [LeetCode #45: Jump Game II](https://leetcode.com/problems/jump-game-ii/).

Return the smallest number of jumps to reach the last position of a reachable input.

## Practice

Read the tests, keep the existing function signatures, and replace the body in
your chosen `solution` file with your own implementation. Run from the repository root.

```bash
npm run practice -- 12_dynamic_programming/problems/jump_game_ii js
npm run practice -- 12_dynamic_programming/problems/jump_game_ii py
npm run practice -- 12_dynamic_programming/problems/jump_game_ii ts
```
