# Wildcard matching

Practice the matching question: [LeetCode #44: Wildcard Matching](https://leetcode.com/problems/wildcard-matching/).

Match a whole string against a pattern with single-character ? and arbitrary-length * wildcards.

## Practice

Read the tests, keep the existing function signatures, and replace the body in
your chosen `solution` file with your own implementation. Run from the repository root.

```bash
npm run practice -- 12_dynamic_programming/problems/wildcard_matching py
```
