# Ugly number

Practice the matching question: [LeetCode #264: Ugly Number II](https://leetcode.com/problems/ugly-number-ii/).

Return the nth positive number whose prime factors are limited to 2, 3, and 5.

## Practice

Read the tests, keep the existing function signatures, and replace the body in
your chosen `solution` file with your own implementation. Run from the repository root.

```bash
npm run practice -- 08_heaps/problems/ugly_number py
```
