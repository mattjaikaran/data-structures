# Rotting oranges

Practice the matching question: [LeetCode #994: Rotting Oranges](https://leetcode.com/problems/rotting-oranges/).

On a rectangular grid, 0 means empty, 1 means fresh, and 2 means rotten. Each minute all rotten cells infect orthogonal fresh neighbors. Return minutes to infect every fresh cell, or -1 if some are unreachable. Mutate infected cells to 2. Empty grids return 0. Use O(rows * columns) time and space.
