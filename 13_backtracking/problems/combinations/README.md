# Combinations

Practice the matching question: [LeetCode #77: Combinations](https://leetcode.com/problems/combinations/).

Choose every group of k distinct values from 1 through n.

## Practice

Read the tests, keep the existing function signatures, and replace the body in
your chosen `solution` file with your own implementation. Run from the repository root.

```bash
npm run practice -- 13_backtracking/problems/combinations py
```
