# Is palindrome

Practice the matching question: [LeetCode #125: Valid Palindrome](https://leetcode.com/problems/valid-palindrome/).

Check whether a string reads the same in both directions after ignoring non-alphanumeric characters and case.

## Practice

your chosen `solution` file with your own implementation. Run from the repository root.
